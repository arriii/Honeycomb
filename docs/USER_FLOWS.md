# User Flows

## First-time user
Sign up → create profile → add known/suspected/avoid/tolerated context → optionally note records → home radar

## Quick scan
Home → Scan → choose or auto-detect scan type → photo/text → analyze → evidence result → save to history

## Flare-up
Home → Skin / flare-up → photo + description → log severity/context → save to journal → optionally connect recent scans

## Appointment
Profile → Appointment Snapshot → review → print/save PDF

## Agent
Agent → text or speech → AI uses selected profile/history context → saved thread
