# Safety & Privacy Rules

1. Never display “you are definitely allergic” based only on an app scan.
2. Never display “safe” just because no match was found.
3. Keep confirmed, suspected, personal avoid, and prior reaction history separate.
4. A flare-up photo can be documented and contextualized; the prototype should not diagnose the condition from the image.
5. The confidence meter describes **evidence confidence**, not medical certainty.
6. Show “unable to verify” when source/product information is incomplete.
7. Show source dates and product-version details when possible.
8. Do not put API keys, medical records, or private user data into a public GitHub repository.
9. The static prototype stores data locally in the browser only.
10. Production document/image storage must be encrypted and access-controlled.
